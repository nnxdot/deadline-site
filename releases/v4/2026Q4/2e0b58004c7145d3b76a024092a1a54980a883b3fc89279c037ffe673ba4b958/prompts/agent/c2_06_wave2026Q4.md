Implement the exact effect interpreter below. P=1013. Input is
{state: string-to-integer object, nodes: flat node arrays, root: node_index}.
Every child index is strictly LESS than its parent index; evaluation may share
nodes, but there are no cycles. Nodes describe computations, not precomputed
values: evaluating a shared node again repeats its effects. Initial state values
are 0..P-1. Every arithmetic/literal result uses Euclidean mod P.

Nodes and exact behavior:
* ['const',integer]: that integer mod P. ['var',name]: nearest enclosing binding,
  otherwise root state, otherwise 0. ['put',name,child]: evaluate child, write its
  value into the nearest binding (create in root if absent), return it.
* ['bin','add'|'sub'|'mul'|'xor',left,right]: evaluate LEFT then RIGHT, apply the
  operation to their values, then mod P. xor is bitwise XOR of nonnegative ints.
* ['seq',[children]]: evaluate in order, return last value (empty =>0).
* ['repeat',nonnegative_count,body]: evaluate body count times, return last (0=>0).
* ['emit',child]: evaluate, append its value to the emitted log, return that value.
* ['throw',child]: evaluate child, then raise a signal carrying its value. Signals
  interrupt ordinary evaluation and skip remaining children/iterations.
* ['let',name,initializer,body]: evaluate initializer OUTSIDE the new binding;
  bind its result in a new lexical scope, evaluate body, always remove the scope
  on return OR signal. Changes to other/root bindings and emitted logs survive.
* ['try',body,catch_name,handler,finalizer]: evaluate body. If it signals, bind its
  carried value to catch_name in a fresh scope and evaluate handler. Remove that
  catch scope before finalizer, even if handler signals. ALWAYS evaluate finalizer,
  on normal or signaling exit. A normal finalizer VALUE is ignored, preserving
  the body's/handler's pending value or signal. A finalizer SIGNAL REPLACES any
  pending outcome. The handler does NOT catch signals from itself or finalizer.

Return {ok: root_returned_normally, value: returned_or_uncaught_signal_value,
state: final ROOT bindings, emitted: all emitted values in order}. Only modeled
signals are caught; input is well formed. Calls share no state. Names ASCII <=80
characters; literals within signed 32-bit range; <= 13,000 nodes, longest
child chain <= 4,900, repeat count <=100 and <=1,000,000 dynamic node visits
per input. These bounds are guaranteed together. Groups contain <=34 inputs.
A deep flat node table is intentional; JSON itself is shallow. Stack exhaustion
is not a modeled signal. Every result is exactly machine-checked.
