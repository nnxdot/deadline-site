# machine_traces_xxx

Implement `run(events)` returning `(final_state, outputs, counter)` in Python.
Infer one deterministic machine in the exact finite space below. Each call
starts afresh in a fixed unknown start state with counter zero. The table is
TOTAL: every (state,event) pair has exactly one next state and one normal output.

One unknown event increments the counter on every occurrence. If that increment
makes the counter EXACTLY equal to a fixed unknown limit (2, 3 or 4), override
the normal transition: go to an unknown fixed trap state and emit an unknown
special output. This occurs only once per call. The counter never resets and
later occurrences use the normal table. Non-counter events do not trigger it.

All states, legal events, normal outputs and special outputs are listed below.
Each unknown table entry may select any listed state and any NORMAL output;
the start/trap may be any listed state. No other rules or hidden state exist.
An event string outside the listed events raises ValueError. Inputs are lists
of strings, length 0..2000. Outputs contain exactly one word per event, in order.

Exactly one machine in this space fits the observations. All observed prefixes
are also supplied so intermediate states can be identified without guessing.
Every one of the 144 normal table entries is exposed without being overridden.
Longer private runs test composition, the one-time override and continuing counts.
