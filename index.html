With code execution, top agents passed every pass/fail task we built, at every size. Open-ended tasks keep room above the best answer.

    The tasks

    8 task kinds, three sizes each.

    Each picture below is drawn from a real public instance of that task.

    One score per task, no ceiling.

    Each hidden instance is scored against two answers we know: a lazy one that is always valid, and our strong reference.

    log(floor / you) / log(floor / ref)
    • 0The lazy answer. It is always valid and easy to write.
    • 1Our reference. A strong solver given generous compute.
    • >1Better than our reference. There is no maximum.
    • -0.15Broken, slow or wrong answers. Below lazy, so careless work costs points.

    An example instance where the lazy answer costs 400 and our reference costs 100. Lower cost is better.

    The board.

    Pilot models run every task three times, community results once. The headline is 100 times the mean over task kinds, so 100 means as good as our reference.

    Fair play

    Hard to game, easy to check.

    Each model works alone in a task folder that holds the exact checker and scorer. The only secret is which instances it will face.
